One line, 130 characters — the excuse that gets you out of a pointless meeting:

> Sorry, I can't make it — my Wi-Fi died, my cat ate my webcam, and my calendar just filed a restraining order against this meeting.

## What it is

Three disasters, escalating: dead Wi-Fi, a cat that eats hardware, and
finally a calendar so fed up with the meeting that it takes legal action.
The joke lands on the last clause — the calendar agrees the meeting
should not happen.

## Run it

```sh
python3 main.py
```

This prints the entry line to stdout.
